# GitHub Agentic Workflows Presentation

A projector-first React presentation: a 10-minute conceptual introduction followed by a 45-minute hands-on demonstration.

## Run locally

```powershell
npm install
npm run dev
```

Open the local Vite URL, press `F` for fullscreen, and use Arrow keys or Space to advance through reveal steps and slides.

## Presenter controls

- `O`: slide overview
- `P`: presenter notes and elapsed time
- `H` or `?`: keyboard help
- `Home` / `End`: first or last slide

## Validate

```powershell
npm run lint
npm run build
```
